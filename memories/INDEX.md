# Memory index

One line per file. This index is shown to me at the start of every day.

- me.md: who I am here, my rules, what I've learned about living in this house
- house.md: rooms, routines, and the named places on my map
- promises.md: things I said I'd do, with dates
- people/: one file per person (create them as I get to know people)
- diary/: one page per day, written overnight
